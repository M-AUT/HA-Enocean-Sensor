# HA-Enocean-Sensor
EnOcean STM 550B / EMSWB (BLE) 

Home Assistant Integration for energy harvesting EnOcean STM 550B and EMSWB BLE sensors.  
Features 
-  Temperature
-  Humidity
-  Illuminance
-  Motion Acceleration X/Y/Z
-  Magnet Contact sensor
-  Energy storage level

Status: Early release

Tested with:
- EnOcean STM 550B
- Home Assistant 2026.x



BLE ID of the Sensor 
Security Key (32 Hex) can be set at the sensor via NFC in the Enocean App. Format must be e.g. 00112233445566778899AABBCCDDEEFF
